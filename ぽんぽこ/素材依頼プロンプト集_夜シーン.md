# 素材依頼プロンプト集（夜の屋根シーン用）— そのままコピペ用

使い方：ChatGPTの画像生成に、**下のプロンプトを1つずつ貼る**。
毎回、**手持ちのドット絵シート画像を「参考」として一緒に添付**すると画風が揃います。
返ってきたら「背景が透明 or 真っ白」「他の物が写り込んでいない」かを確認。ダメなら再依頼。

まずは ★ の5つ（夜空・月・雲・屋根・ぽんた）だけでも1本作れます。

---

## ★① 夜空ベース（背景・これだけ透過不要）

```
かわいいドット絵（ピクセルアート）で、夜空だけの背景を1枚作ってください。
縦長9:16（1080×1920）。上が濃紺で、地平線に向かって少し明るくなる夜のグラデーション。
星・月・雲・建物・キャラクターは入れず、空だけにしてください。
添付画像と同じ色調・タッチで。
```

## ★② 月

```
かわいいドット絵で、三日月を1つだけ作ってください。
背景なしの透過PNG（無理なら真っ白な背景）で、月だけを単体で。やわらかい黄色。
添付画像と同じタッチで。
```

## ③ 星（大・小セット）

```
かわいいドット絵で、夜空用の星を作ってください。
4方向にキラッと光る大きめの星を数個と、小さな点の星を散らしたセット。
背景なしの透過PNG（無理なら真っ白な背景）。添付画像と同じ色調で。
```

## ★④ 雲（3種）

```
かわいいドット絵で、夜の雲を3種類、それぞれ単体で作ってください。
背景なしの透過PNG（無理なら真っ白な背景）。青灰色の落ち着いた色。
横に無限スクロールさせたいので、左右がつながって繰り返せる形が理想です。
添付画像と同じタッチで。
```

## ⑤ 山（遠景・横長）

```
かわいいドット絵で、遠くの山のシルエットを横長で作ってください。
背景なしの透過PNG（無理なら真っ白な背景）、山だけ。夜の青紫色。
横に流してループさせたいので、左右の端がつながる形にしてください。幅は広め（例：1600×400）。
添付画像と同じ色調で。
```

## ⑥ 街並み（遠景・横長・窓の灯り付き）

```
かわいいドット絵で、遠くの街並み（家々）のシルエットを横長で作ってください。
ところどころ窓に暖色の灯り。背景なしの透過PNG（無理なら真っ白な背景）。
横にループさせたいので左右の端がつながる形に。夜の色。幅は広め。
添付画像と同じタッチで。
```

## ★⑭ ぽんた（屋根で寝ているポーズ・主役）

```

頭のてっぺんに葉っぱが1枚。茶色の体・こげ茶のたぬきマスク・クリーム色のお腹・縞々のしっぽ。
背景なしの透過PNG（無理なら真っ白な背景）。
かわいい寄りで（リアル調・白目むき・閉じ目「><」・怖い顔は禁止）。
添付画像と同じ色調・タッチで。
```

### 動きを増やしたい時の追加依頼（任意）

ぽんたを呼吸や歩きで動かしたいなら、コマ分けで頼む：

```
このぽんたの「寝ている呼吸」を2〜3コマ（少し膨らむ→戻る）で、
等間隔・同じ大きさ・同じ足元位置で、透過PNG（無理なら真っ白背景）で作ってください。
```
```
このぽんたの「歩き」を横向き4コマで、等間隔・同じ大きさ・同じ接地位置、
透過PNG（無理なら真っ白背景）で作ってください。
```
